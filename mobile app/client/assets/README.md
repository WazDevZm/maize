# Assets Directory

This directory contains the app's static assets:

- `icon.png` - App icon (1024x1024)
- `adaptive-icon.png` - Android adaptive icon (1024x1024)
- `splash.png` - Splash screen image (1284x2778 for iPhone 12 Pro Max)
- `favicon.png` - Web favicon (48x48)

## Asset Requirements

### App Icon (icon.png)
- Size: 1024x1024 pixels
- Format: PNG with transparency
- Used for: iOS app icon, Android launcher icon

### Adaptive Icon (adaptive-icon.png)
- Size: 1024x1024 pixels
- Format: PNG with transparency
- Used for: Android adaptive icon foreground
- Note: Keep important content within the center 768x768 area

### Splash Screen (splash.png)
- Size: 1284x2778 pixels (or similar high resolution)
- Format: PNG
- Used for: App loading screen
- Background color is set in app.json

### Favicon (favicon.png)
- Size: 48x48 pixels
- Format: PNG
- Used for: Web version favicon

## Generating Assets

You can use online tools or design software to create these assets:

- [Figma](https://figma.com)
